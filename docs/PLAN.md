# CABO 已批准实施方案

实现本机部署、最多四个独立房间、每房间 2–4 人的局域网网页游戏。TypeScript + React/Vite + Express/Socket.IO，内存保存状态，服务重启重新开始。模块：apps/web、apps/server、packages/game。

## 规则
- 52 张：四花色 A–Q、黑桃/红桃 K、两张 Joker（0 分）。每人4张暗牌。
- 开局30秒选择两张，超时最左补选；查看10秒，可提前盖回。技能查看5秒，受60秒回合期限限制，不保留提示。
- 单牌交换成功；多牌同点成功。新牌放最小序号，其余选中位置移除并紧凑。旧牌升序进弃牌堆。失败旧牌原位公开，抽牌追加；摸牌堆来源暗置，弃牌堆来源明置，数量不限。
- 摸牌堆7/8看自己，9/10看对手，J/Q可交换任意两名不同玩家各一张牌，包括自己与对手或两名对手，双方序号不限。公开状态随牌。弃牌堆取牌立即公开并保持明牌，不能发动技能。9/10公开目标玩家和序号，不公开牌面；所有玩家与观战者均显示原服务端时间起5秒的提示。
- 抽牌前CABO占回合，其他人各一次且不可再呼唤。呼唤者并列最低0分，否则自身手牌分加10。摸牌堆耗尽完成当前回合即结算，不洗回。
- 恰好QQKK者0，其余50，优先于CABO。累加后每人首次恰好100重置50，处理后任意人>100结束，最低同分并列赢家。
- 首轮随机首家，后续按座位轮换。轮末全部明牌，至少8秒后房主开下一轮；终局重新开场清空积分与触发记录。
- 回合60秒，超时未抽则摸牌弃置，已抽则弃置，不发动技能。

## 服务/隐私
RoomManager 统一注册网络连接，每房间独立引擎、版本、玩家/观战者、去重记录和计时。唯一 100ms 定时器检查所有房间；有变化才推状态，摘要变化才广播列表。最多四间，每浏览器身份最多一席；创建者为房主。进行中返回列表或跨房观战保留席位，大厅切换先离座。最后席位离开立即关房；全玩家离线满 5 分钟关房（观战不延长）。房主可确认关闭房间，“结束整场”只回本房间大厅。

首次请求前持久化 getRandomValues 身份和待处理请求号。创建、加入、恢复幂等；私密查询可找回席位，并通过精确请求回执认定确认丢失。轮换恢复凭据和连接代次；命令/状态校验 serverId、roomId、generation，旧页不得自动抢回新连接。网络/超时/限流保留身份，以 1/2/4/8 秒封顶自动重试；真正失效与接管明确提示。只恢复当前状态，不排队重放断线游戏命令。URL 保存房间及观战模式，不含身份；前进/后退执行相同切换流程。无可写存储拒绝入座仍可观战。旧版凭证失效，无服务器重启持久化。

暗牌无点数/真实标识，pending、reveal、swapFeedback 只发本人；原服务端截止时间刷新不延长。公共房间摘要不含牌面。J/Q 成功日志向所有玩家和观战者显示“甲发动了交换技能：乙第 2 张 ↔ 丙第 4 张。”，失败不生成，日志 at + 5000 到期。

## UI/交付
深绿中文牌桌；手机自牌/操作优先、选对手再选位；桌面全桌。点击+确认、44px触控、编号、多牌换行、服务端输入锁、短动画。展示回合/倒计时/牌数/CABO剩余/连接。独立私密遮罩。54张SVG+牌背+8操作图标。
命令 npm install/dev/build/start/typecheck/test/test:e2e。生产0.0.0.0:3000同端口，打印局域网地址。提供房间列表与公开观战；无二维码、账号、机器人或聊天。

## 验收

## 换牌后的新牌位置提示（后续批准方案）

- 交换完成后，由服务端给操作玩家返回可选 `swapFeedback`，只包含结果、最终位置和完成后 5 秒的截止时间，不包含牌面或真实牌标识，操作命令不变。
- 单张使用“换牌成功”，多张使用“合并成功”或“合并失败”，同时提示第几张；成功取所选最小序号，失败取追加后末尾位置。
- 新牌保持背面，仅新牌显示金色边框、“新换入”与一次轻微落位强调，替换整组手牌重播动画。减少动态效果时保留边框和文字。
- 普通更新不延长，刷新只恢复剩余时间；技能换走该位置、结算、大厅或新轮立即清除。
- 覆盖单张、多张成功/失败、紧凑排列、期限/刷新、技能清除、拒绝操作、视图隐私，以及 Chromium/WebKit 桌面与手机视口；运行类型检查、规则/联网测试和构建。
