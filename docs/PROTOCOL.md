# 联网与状态边界

## 客户端消息

- `join({name?, token?}, ack)`：首次昵称入座；重连使用 token。成功返回 `{ok:true,token,view}`。凭证仅通过本连接确认发回，不出现在广播、日志或其他玩家视图。
- `sync(ack)`：已验证身份主动获取当前完整个人视图。
- `command({requestId,version,command}, ack)`：类型定义见 `packages/game/src/types.ts`。返回 `{ok,error?,view?}`，错误含 code/message。必须从最新视图取版本；失败后显示原因并重新选择/确认。
- 服务端 `state(view)`：针对每个连接分别构造。`takenOver` 告知被新连接接管；`removed` 告知大厅席位被移除。

每个事件同步执行，入口只读取一次时钟。先处理该时间之前的超时，再校验身份、请求格式、去重、版本和规则。游戏状态版本统一由房间层管理，事件处理内所有投影使用同一时间，避免截止时刻跨越校验和执行。

每个身份缓存最近 256 个请求 ID 的操作结果；缓存不保存旧视图。重复请求返回原操作结果和**当前**个人视图，避免重播过期私密牌面。更老请求携带的旧版本会被拒绝。客户端超时可使用同一请求 ID 重试一次，之后同步完整状态。服务器重启清空会话和去重缓存。

Socket.IO 默认不保证断线期间的消息重发，因此重连不依赖消息补发，而是重新验证身份和获取完整视图。参考 [Socket.IO 投递保证](https://socket.io/docs/v4/delivery-guarantees/)。

## 牌面过滤

暗牌只包含 `{index,public:false}`，没有真实牌 ID、点数或花色；自身暗牌也不例外。公开失败牌和轮末手牌才带 `card`。待处理 `pending` 只出现在当前玩家视图。开局/技能 `reveal` 只发给获准玩家，包含绝对截止时间，过期后删除；前端同时按截止时间隐藏，断线立即隐藏查看遮罩。正常手牌总分只在结算时公开。

公共日志只记录动作，不记录私密点数。前端仅 localStorage 持久化身份 token，不持久化游戏视图或牌面。浏览器使用原生 JSX 转义昵称。生产无测试场景控制接口。

## 换牌位置提示

成功处理 `swap` 后，仅操作玩家的 `PlayerView` 可包含 `swapFeedback: {outcome,index,deadline}`。`outcome` 为 `swap-success`（单张）、`merge-success`（多张同点）或 `merge-failed`（多张不同点）；`index` 为从 0 开始的最终位置，成功取所选最小序号，失败取追加后的末尾。字段不包含牌面或真实卡牌标识，命令格式保持不变。

`deadline` 是交换完成时间加 5000 毫秒的服务端绝对时间。广播、同步、重试、刷新均不重新计时；过期不再返回，前端同时按服务器时钟偏移隐藏提示。后续 J/Q 技能换走该位置时清除受影响玩家的提示，结算、大厅、新轮也不保留。被拒绝的操作不会生成新提示。

前端仅给自己的新牌显示金色边框、“新换入”和结果位置文案；牌仍为暗牌。落位强调只播放一次，普通状态更新不重播；减少动态效果偏好关闭动画，但保留边框与文字。

## 生命周期

房主转移按入座顺序选在线玩家；全部离线暂保首个席位作为可恢复房主。大厅全离线 60 秒清理，活动对局不因离线删除。房间容量 4，昵称 1–24 字符，消息上限 8 KiB；连接内 join/command 限流 100 次/10 秒。首发设计用于可信局域网，未提供互联网账号系统或持久化数据库。


## 任意位置交换与技能提示（2026-10-09）

7–10 沿用 `skill {targetId,index}`。J/Q 使用 `exchange {first:{playerId,index},second:{playerId,index}}`，两张牌分别指定玩家和从 0 开始的位置；可选自己和对手，也可选两名对手。两名玩家必须不同，两处都必须有牌；无需相同序号或相同手牌数量。旧的 J/Q 单位置 `skill` 请求被拒绝，不隐式补选位置。

服务器验证当前回合、牌堆来源、J/Q、玩家和位置后一次性交换，公开状态跟随牌移动，清除各自被移动位置的 `swapFeedback`。校验失败不交换、不弃置待处理功能牌，客户端可重新选择。交换不新增私密揭示。

成功使用技能时，公共日志增加 `skill:{actorId,kind}`，`kind` 为 `peek`、`spy` 或 `exchange`。字段不含被查看的牌面。其他玩家显示“某某 发动了偷看／间谍／交换技能”，使用日志的服务端时间 `at + 5000` 到期；操作玩家已有自己的技能反馈，不显示此提示。刷新不会延长展示时间；立即进入结算或终局时仍显示至原截止时间，返回大厅后不显示。
